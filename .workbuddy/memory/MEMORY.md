## 数据更新规则
- 只更新scenicData数组的announcement字段和header时间戳
- 不改动CSS/交互功能
- 闭园天数每天推进1天
- 公告类型：danger(全域闭园)、warning(部分管控)、info(正常/活动公告)
- 注意：黄果树水帘洞售罄是分批次公告（10批7/6-7/23），不是单一公告，日期范围为7/14-8/10共28天
- ⚠️关键陷阱：中文文本中不能使用ASCII双引号（"..."），会提前关闭JS字符串。必须用中文「」或""等全角引号
